Manual Crop Debug Test

This test loads the main app and guides you through testing the crop functionality step by step.

Step 1: Load Main Application

Step 2: Manual Test Instructions

Test Steps:

  1. Open Photos Panel: Click on "Photos" in the left toolbar
  2. Add an Image: Drag any photo from the panel to the canvas
  3. Select the Image: Click on the image to select it
  4. Check Canvas Top Bar: Look for crop controls in the top bar
  5. Test Crop Positions: Try different crop positions from dropdown
  6. Observe Console: Open browser DevTools and watch console logs

What to Look For:

  • ✅ Crop button appears when image is selected
  • ✅ Dropdown shows all 9 crop positions
  • ✅ Console shows crop debug logs with calculations
  • ✅ Image visually changes when crop position is selected
  • ❌ Only center crop works - other positions don't show visual changes

Debug Console Commands:

// Check if canvas store is accessible
window.useCanvasStore

// Check if Konva stage is accessible
window.konvaStage

// Check current elements
window.useCanvasStore.getState().elements

// Check current selection
window.useCanvasStore.getState().selection
